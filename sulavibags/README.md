# ThreatEye

Workspace inteligente para organizar documentos, consultar uma base de conhecimento e interagir com um assistente de IA.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Rotas

- `/` — dashboard
- `/arquivos` — gerenciamento de arquivos
- `/assistente` — conversa com o assistente
- `/configuracoes` — preferências do workspace
- `/ajuda` — central de ajuda

## Validação

```bash
npm run lint
npm run build
```
